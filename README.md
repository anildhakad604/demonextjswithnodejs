# Next.js + Node.js E-commerce Starter

## Stack
- Frontend: Next.js App Router + TypeScript
- Backend: Node.js + Express + TypeScript
- Cart: localStorage starter implementation
- API: products and health endpoints

## Run
```bash
npm install
npm run install:all
npm run dev
```

Frontend: http://localhost:3000
Backend: http://localhost:5000

## Next production steps
Connect PostgreSQL/MongoDB, add authentication, admin panel, image uploads, payment gateway, orders, coupons, inventory, and deployment configuration.
